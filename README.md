# EstateIQ – Real Estate Investment Advisor

**An End-to-End Machine Learning Application for Property Investment Analysis and Future Price Prediction**

EstateIQ is a machine learning-based real estate investment advisor designed to help users explore property market data, evaluate investment potential, and estimate property values over a five-year period.

The project combines data analysis, machine learning, experiment tracking, and an interactive Streamlit dashboard into one application.

## Project Objectives

- Analyze Indian housing market data to identify property trends and patterns.
- Classify properties into investment price categories: Low, Medium, and High.
- Predict estimated property prices after five years.
- Compare machine learning algorithms using appropriate evaluation metrics.
- Track model experiments using MLflow.
- Provide an interactive dashboard for property exploration and investment prediction.

## Key Features

### 1. Property Explorer
- Explore housing market data across Indian states and cities.
- Filter properties by state, property type, and number of bedrooms.
- View key property statistics and visualizations.
- Explore property listings and pricing patterns.

### 2. Investment Predictor
- Enter property characteristics such as area, bedrooms, bathrooms, floors, and current price.
- Predict the property's price category.
- Estimate its price after five years.
- View predictions generated by trained machine learning models.

### 3. Machine Learning Models

**Classification**
- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

**Regression**
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

The best-performing models are saved and integrated into the Streamlit application.

## Datasets

The project uses two separate datasets:

**1. India Housing Prices Dataset**
- Used for property exploration, exploratory data analysis, and dashboard visualizations.
- Contains property information such as location, property type, area, price, furnishing status, and amenities.

**2. House Price Regression and Classification Dataset**
- Used for machine learning model training and prediction.
- Contains property features, current prices, future price values, and price categories.

The two datasets serve different purposes and are not directly linked.

## Model Performance

The following results were obtained using an 80:20 train-test split.

### Classification Results

| Model | Accuracy | Macro F1-Score |
|---|---:|---:|
| Logistic Regression | 74% | 0.7408 |
| Random Forest | 71% | 0.7128 |
| Gradient Boosting | 75% | 0.7471 |

## MLflow Experiment Tracking

MLflow is used to track machine learning experiments, including:
- Model parameters
- Evaluation metrics
- Experiment runs
- Model comparison

To launch the MLflow dashboard:

```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db
```

Open `http://127.0.0.1:5000` in your browser.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nidhipadhiyar/real-estate-investment-advisor.git
```

### 2. Navigate to the project directory

```bash
cd real-estate-investment-advisor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
streamlit run app/app.py
```

The application will open in your browser.

## Training the Models

To retrain the classification and regression models:

```bash
python src/train_model.py
```

The trained models will be saved in the `models/` directory.

## Limitations

- The five-year price predictions are based on the patterns in the supplied training dataset and should not be interpreted as guaranteed real-world property valuations.
- The training dataset contains synthetic-looking future price patterns, so the predictions require validation against independent real-world data before practical investment use.
- The predicted price categories represent the dataset's classification labels, not a comprehensive assessment of investment risk or profitability.
- EstateIQ is an educational machine learning project and does not provide financial or investment advice.
